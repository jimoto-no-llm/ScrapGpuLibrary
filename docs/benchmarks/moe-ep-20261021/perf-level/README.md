# AMD の電力プロファイル固定（`power_dpm_force_performance_level`）の効果

TB250、LFM2.5-8B-A1B Q4_0、llama-bench `-fa 0 -t 2 -r 5`、bench lock 下。`high` は `sudo sgl-driver-switch perf high`（RX 6400 と WX 2100）、測定後に `auto` へ戻した（`logs/perf.log`）。コマンドは `run.sh`。

| 構成 | 設定 | pp512 | tg128 | pg512,128 |
| --- | --- | --- | --- | --- |
| C1（RX+WX Vulkan 層分割 `-ts 5/1 -ub 512`） | auto | 630.79 ± 3.78 | 44.17 ± 0.35 | 170.17 ± 1.45 |
| C1 | auto + `GGML_VK_FORCE_MMVQ=1` | 636.82 ± 4.46 | 44.73 ± 0.36 | 171.88 ± 1.23 |
| C1 | high | 657.39 ± 3.75 | 43.96 ± 0.41 | 171.36 ± 1.15 |
| C1 | **high + MMVQ** | **657.45 ± 4.72** | **45.06 ± 0.16** | **173.50 ± 0.93** |
| C0（RX 6400 Vulkan `-ncmoe 5 -ub 128`） | auto | 71.76 ± 0.19 | 28.25 ± 2.22 | 50.16 ± 1.67 |
| C0 | auto + MMVQ | 71.85 ± 0.18 | 24.97 ± 1.43 | 52.17 ± 2.33 |
| C0 | high | 71.83 ± 0.19 | 25.47 ± 1.46 | 51.00 ± 1.77 |
| C0 | high + MMVQ | 71.83 ± 0.13 | 25.59 ± 0.81 | 52.71 ± 1.35 |

- `high` は C1 の pp512 を約 4 % 上げるが、tg は変えない（decode はクロックではなく帯域と直列実行で決まる。c1-profile と整合）。
- `GGML_VK_FORCE_MMVQ=1` は C1 の tg を約 2 % 上げる。KLD は未測定。
- C0 の tg は分散が大きく（± 0.8〜2.2）、設定間の差は誤差内。
- `sclk_*.txt` は測定後のアイドル時に読んだため、負荷時のクロックは記録できていない。
- **以後の比較相手**: 設定だけで得られる C1 の最良値（high + MMVQ）pp512 657.5 / tg128 45.1 / pg 173.5 を、既存構成の上限として扱う。
